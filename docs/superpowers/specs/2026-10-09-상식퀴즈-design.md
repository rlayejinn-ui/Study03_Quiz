## 1. 화면과 흐름

### 1.1 화면 구성

`index.html`에 화면 5개를 `<section>`으로 미리 만들고 한 번에 하나만 보이게 한다. `script.js`는 빈칸(문제 문장, 보기, 점수 등)만 채운다.

| 화면 | 내용 | 단계 |
|---|---|---|
| 시작 | 카테고리 버튼 4개, "연습 모드 · 순위표에 기록되지 않음" 문구 | 1 |
| 모드 선택 | 연습/스피드/힌트 3개와 한 줄 규칙. 연습에 "순위표에 기록되지 않음" | 2 |
| 문제 | 카테고리·진행(3 / 10), 문제문, 보기 4개, 타이머(스피드만), [힌트](힌트만), [그만하기], 해설 영역 | 1 |
| 결과 | 점수, 모드별 영역, [다시 하기] [처음으로] | 1 |
| 순위표 | 모드 × 카테고리 8개 목록 중 고른 목록의 상위 10개 | 3 |

- 해설은 별도 화면이 아니라 **문제 화면 안의 해설 영역**이다. 보기를 고르면 정오, 정답, 한 줄 해설, 출처, [다음]이 나온다. 마지막 문항에서는 [다음] 대신 [결과 보기].
- 한 판의 문항 순서와 보기 순서는 매번 무작위로 섞는다.

### 1.2 한 문제의 흐름

```
출제 ─┬─ 보기 선택 ─────┐
      └─ 15초 경과(스피드) ┴→ 해설 표시(보기 잠금, 점수 계산) ─ [다음] → 다음 문항 출제 … → 10번째 후 결과
```

| 시점 | 연습 | 스피드 | 힌트 |
|---|---|---|---|
| 출제 | 보기만 표시 | 타이머 15초 시작 | [힌트] 버튼 활성 |
| [힌트] 클릭 | — | — | 오답 2개 제거, 버튼 비활성 |
| 보기 선택 | 판정, 해설 | 타이머 정지, 판정, 해설 | 판정(힌트 썼으면 0.5점), 해설 |
| 15초 경과 | — | 오답(0점), 정답 강조, 해설 | — |
| [다음] | 다음 문항 | 다음 문항, 타이머 15초부터 | 다음 문항, 힌트 버튼 초기화 |

### 1.3 결과 화면의 모드별 영역

- 연습: "순위표에 기록되지 않음" 표시. 틀린 문제가 있으면 [틀린 문제만 다시 풀기] (2단계).
- 스피드·힌트: 닉네임 입력칸과 [순위표에 기록] (3단계).

### 1.4 단계별로 보이는 것

- 1단계: 시작, 문제, 결과. 모드 선택이 없어 항상 연습으로 진행한다.
- 2단계: 시작과 문제 사이에 모드 선택이 들어간다.
- 3단계: 순위표 화면과 닉네임 입력이 추가된다.

## 2. 데이터와 `script.js` 구조

### 2.1 `questions.js`

전역 상수 하나만 정의하며 로직은 두지 않는다.

```js
const 문항목록 = [
  { 카테고리: "한국사", 문제: "…", 보기: ["…","…","…","…"], 정답: 2, 해설: "…", 출처: "…" },
  // 카테고리마다 10개, 총 40개
];
```

`정답`은 `보기` 배열에서의 위치(0~3)이다. `해설`은 한 줄, `출처`는 해설 영역에 함께 표시된다. 카테고리 4개의 목록은 `script.js`가 가진다.

### 2.2 `script.js` — 6개 블록 (위에서 아래 순서)

| 블록 | 내용 | DOM 사용 |
|---|---|---|
| ① 상수 | `카테고리목록`, `문항수 = 10`, `모드설정`, 순위표 키·보관 개수 | 없음 |
| ② 순수 로직 | 아래 함수 목록 | 없음 |
| ③ 상태 | 상태 객체 `상태` 하나 | 없음 |
| ④ 저장소 (3단계) | `순위표읽기`, `순위표쓰기` (모두 `try/catch`) | 없음 |
| ⑤ 화면 그리기 | `화면보이기(이름)`, `시작화면그리기`, `문제그리기`, `해설보이기`, `결과그리기` 등 | 있음 |
| ⑥ 이벤트와 시작 | 클릭 처리 함수, 마지막에 형식 점검 후 시작 화면 표시 | 있음 |

**모드는 설정 값으로 표현**한다. 화면·이벤트 코드는 모드 이름을 `if`로 가르지 않고 이 값만 본다.

```js
const 모드설정 = {
  연습:   { 제한시간: null, 힌트: false, 맞힘점수: 1, 힌트후점수: null, 순위표: false, 다시풀기: true },
  스피드: { 제한시간: 15,   힌트: false, 맞힘점수: 1, 힌트후점수: null, 순위표: true,  다시풀기: false },
  힌트:   { 제한시간: null, 힌트: true,  맞힘점수: 1, 힌트후점수: 0.5,  순위표: true,  다시풀기: false },
};
```

**순수 로직 함수** (화면과 무관, 입력과 결과만 있음)

| 함수 | 하는 일 |
|---|---|
| `섞기(배열)` | 원본을 건드리지 않고 무작위로 섞은 새 배열 반환 (Fisher–Yates) |
| `판만들기(카테고리)` | 해당 카테고리 10문항을 섞고, 문항마다 보기를 섞어 "출제 문항"(`{문제, 보기:[{글, 정답여부}], 해설, 출처}`)을 만듦 |
| `지울보기고르기(출제문항)` | 오답 3개 중 무작위 2개의 위치를 반환 (힌트용) |
| `점수계산(모드, 맞힘, 힌트썼음)` | 맞히고 힌트를 썼으면 `힌트후점수`, 맞히면 `맞힘점수`, 틀리면 0 |
| `형식점검(문항목록)` | 카테고리당 10개, 보기 4개, `정답` 0~3, `해설`·`출처` 비어 있지 않음을 확인해 오류 목록 반환 |
| `순위표에넣기(목록, 기록)` | 점수 높은 순, 동점이면 먼저 달성한 기록 우선으로 정렬해 상위 10개만 남기고 순위 반환 (3단계) |

**상태 객체**

```js
const 상태 = {
  모드, 카테고리,
  출제목록, 현재번호,
  점수, 오답목록,            // 오답목록: 틀린 출제 문항. 다시 풀기에 사용
  힌트사용, 해설중,          // 문항마다 초기화. 해설중은 "선택"과 "시간 초과"가 겹쳐도 한 번만 처리하는 안전장치
  마감시각, 타이머,          // 스피드용
  다시풀기중, 다시풀기정답수, // 다시 풀기 판은 첫 판 점수를 건드리지 않고 이 값만 올림
};
```

### 2.3 데이터 흐름과 주요 동작

```
클릭 → 이벤트 처리 함수 → 순수 로직으로 상태 갱신 → 그리기 함수가 화면에 반영
```

- **스피드 타이머:** 문항을 낼 때 `마감시각 = Date.now() + 15000`으로 정하고, 0.2초마다 남은 시간을 다시 계산해 표시한다. 0 이하가 되면 시간 초과 처리. 해설이 나오면 타이머를 끄고, [다음]에서 새로 정한다.
- **다시 풀기:** `오답목록`으로 새 출제 목록을 만들고(문항·보기 다시 섞음) 연습 규칙으로 진행한다. 끝나면 "n개 중 m개 정답"을 보여 주고, 첫 판 점수는 바뀌지 않는다. 다시 풀고도 틀린 문항이 있으면 같은 방식으로 반복할 수 있다.
- **그만하기:** 타이머를 끄고 상태를 초기화한 뒤 시작 화면으로 간다. 점수는 저장하지 않는다.

### 2.4 예외 처리

| 상황 | 동작 |
|---|---|
| `형식점검`에서 오류 발견 | 시작 화면 대신 오류 화면에 어느 문항이 왜 틀렸는지 표시 |
| `localStorage` 사용 불가 또는 저장값 깨짐 | 빈 순위표로 취급하고 순위표 쪽에만 "순위표를 저장할 수 없음" 안내. 퀴즈는 정상 진행 |
| 선택과 시간 초과가 동시에 발생 | `해설중`이 이미 켜져 있으면 두 번째 처리를 무시 |

## 3. 구현 순서와 확인 방법

### 3.1 순서

```
[선행] 문항 40개 작성 + 출처 확인 + 사용자 검토 → 1단계 → 2단계 → 3단계
```

각 단계는 끝날 때마다 **확인한 것과 확인하지 못한 것을 구분해 보고**하고, 사용자 확인 뒤 다음 단계로 넘어간다. 단계마다 한글 메시지로 커밋한다.

### 3.2 확인 방법 세 가지

| 방법 | 내용 |
|---|---|
| 콘솔 검사 | 페이지를 연 뒤 브라우저에서 순수 함수를 직접 호출해 기대값과 비교 (이 컴퓨터에는 Node가 없어 이 방식을 씀) |
| 화면 조작 | 내장 브라우저에서 `file:///C:/학교과제/Study03_Quiz/index.html`을 열고 클릭하며 화면·텍스트 확인. `file://`을 못 열면 구현 시작 때 알리고 Edge/Chrome에서 직접 열어 확인하는 방법으로 바꿈 |
| 문항 검수 | 형식은 `형식점검`으로 자동 확인. 정답이 하나인지, 출처를 실제 열람해 확인했는지, 최상급 표현에 기준과 시점이 있는지는 사람이 읽고 확인 |

### 3.3 1단계 — 연습 모드와 점수

| 확인 항목 | 방법 | 기대 결과 |
|---|---|---|
| `점수계산` | 콘솔 | 연습에서 맞힘 → 1, 틀림 → 0 |
| `판만들기("과학")` | 콘솔 | 10개. 문항마다 보기 4개 중 정답이 정확히 1개. 보기 글 집합은 원본과 같음 |
| `섞기` | 콘솔 | 원본 배열은 그대로이고, 여러 번 돌리면 순서가 다르게 나옴 |
| `형식점검` | 콘솔 | 정상 데이터는 오류 0건. 보기 3개, 해설 비움, 정답 4처럼 일부러 깨뜨린 사본은 각각 오류로 보고됨 |
| 한 판 진행 | 화면 | 카테고리 4개 → 10문제. 모두 정답이면 10 / 10, 모두 오답이면 0 / 10, 일부만 맞히면 그 개수만큼 |
| 해설과 잠금 | 화면 | 보기를 고르면 정오, 정답, 해설, 출처가 바로 나오고 다시 고를 수 없음 |
| 안내 문구 | 화면 | 시작 화면과 결과 화면에 "순위표에 기록되지 않음" |
| 섞임 | 화면 | 같은 카테고리를 두 번 풀면 문항 순서와 보기 순서가 달라짐 |
| 그만하기 | 화면 | 확인 후 시작 화면으로 돌아가고 점수는 남지 않음 |

### 3.4 2단계 — 스피드·힌트 모드, 모드 선택, 틀린 문제 다시 풀기

| 확인 항목 | 방법 | 기대 결과 |
|---|---|---|
| `점수계산` | 콘솔 | 힌트: 힌트 쓰고 맞힘 0.5, 안 쓰고 맞힘 1, 틀림 0. 스피드: 맞힘 1, 틀림 0 |
| `지울보기고르기` | 콘솔 | 100번 반복해도 항상 2개이고, 서로 다르고, 정답 위치를 포함하지 않음 |
| 모드 선택 | 화면 | 카테고리 선택 뒤 모드 선택이 나오고, 연습에 "순위표에 기록되지 않음" 표시 |
| 스피드 타이머 | 화면 | 아무것도 안 누르고 실제로 15초를 기다림 → 오답 처리, 정답 강조, 해설 표시. 해설 중에는 남은 시간이 더 줄지 않고, [다음] 뒤 15초부터 셈 |
| 스피드 선택 | 화면 | 보기를 고르면 타이머가 즉시 멈춤 |
| 힌트 | 화면 | 버튼은 문항당 1번만 눌림. 누르면 보기 2개(정답 포함)만 남음. 쓰고 맞히면 0.5점, 결과는 `7.5 / 10` 형식 |
| 다시 풀기 | 화면 | 오답이 k개면 k문항이 나옴. 끝나면 "k개 중 m개 정답"이 보이고 첫 판 점수는 그대로. 오답 0개면 버튼이 안 보임. 스피드·힌트 결과에는 이 버튼이 없음 |

### 3.5 3단계 — 점수 저장과 순위표

| 확인 항목 | 방법 | 기대 결과 |
|---|---|---|
| `순위표에넣기` | 콘솔 | 11번째 기록은 상위 10개만 남음. 동점은 먼저 달성한 기록이 위. 10위 밖이면 저장되지 않음 |
| 닉네임 | 화면 | 11자 이상 입력 불가, 비우고 기록하면 "익명". 연습 결과에는 입력칸이 없음 |
| 목록 분리 | 화면 | 스피드·한국사 기록이 힌트·과학 목록에 섞이지 않음 (8개 목록) |
| 영속성 | 화면 | 기록 후 새로고침해도 남아 있음 |
| 저장 실패 | 콘솔 + 화면 | `localStorage.setItem`이 예외를 던지게 바꾸거나 저장값을 깨뜨려도(`{{`) 퀴즈는 정상이고 순위표 쪽에만 안내가 나옴 |

### 3.6 모든 단계 공통

- 콘솔 오류 0건.
- 폭 360px에서 가로 스크롤 없음.
- Chrome이나 Edge로 `file://` 더블클릭 동작 확인.
